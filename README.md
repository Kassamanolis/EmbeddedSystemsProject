# Ενσωματωμένα Συστήματα Πραγματικού Χρόνου: Εργασία

Υλοποίηση πολυνηματικού ενσωματωμένου συστήματος πραγματικού χρόνου για την επεξεργασία και καταγραφή δεδομένων τηλεμετρίας από το Bluesky Jetstream Firehose

## Δομή Αρχείων


- monitor.c – Η κύρια εφαρμογή σε C (υλοποίηση Producer, Consumer και Monitor threads)
- Makefile – Κανόνες μεταγλώττισης (build rules) για τη δημιουργία του εκτελέσιμου
- analysis.m – Script μετα-επεξεργασίας σε MATLAB για την ανάλυση του Jitter, του φόρτου δικτύου και της χρήσης CPU
- metrics_log.txt – (Δημιουργείται κατά την εκτέλεση) Το αρχείο CSV με τα αποτελέσματα των μετρήσεων

## Σύσταση Λειτουργικού Συστήματος

Προτείνεται η μεταγλώττιση και εκτέλεση του κώδικα αποκλειστικά σε περιβάλλον **Linux** (π.χ. Raspberry Pi OS, Ubuntu) ή **WSL** (Windows Subsystem for Linux). Η εφαρμογή αξιοποιεί POSIX threads (`pthreads`) και εξειδικευμένες κλήσεις του Linux kernel (όπως το `/proc/stat` για τη χρήση CPU και η `clock_nanosleep` με απόλυτο χρόνο `TIMER_ABSTIME`), οι οποίες δεν μεταγλωττίζονται και δεν υποστηρίζονται εγγενώς σε native Windows. Το σύστημα σχεδιάστηκε και αξιολογήθηκε σε **Raspberry Pi Zero 2 W**.

## Εξαρτήσεις (Dependencies)

Πριν από τη μεταγλώττιση του project, βεβαιωθείτε ότι είναι εγκατεστημένο το παρακάτω λογισμικό:
* `make`
* `gcc` (με υποστήριξη για `pthreads` και `lrt` - Standard C/POSIX libraries)
* `libwebsockets-dev` (για τη διαχείριση της ασύγχρονης σύνδεσης με το Firehose)
* `libcjson-dev` (για την αποκωδικοποίηση των raw JSON frames)
* `MATLAB` (απαιτείται μόνο για την εκτέλεση του `analysis.m` και την παραγωγή διαγραμμάτων)
