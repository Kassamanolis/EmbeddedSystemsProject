# Ενσωματωμένα Συστήματα Πραγματικού Χρόνου: Εργασία

Υλοποίηση πολυνηματικού ενσωματωμένου συστήματος πραγματικού χρόνου για την επεξεργασία και καταγραφή δεδομένων τηλεμετρίας από το Bluesky Jetstream Firehose

## Δομή Αρχείων
- common.h
- main.c 
- producer.c
- consumer.c
- monitor.c
- circular_buffer.c
- counters.c
- Makefile 
- metrics_log.txt 

## Dependencies

Πριν από τη μεταγλώττιση του project, πρέπει να είναι εγκατεστημένα τα παρακάτω:
* make
* gcc
* libwebsockets-dev
* libcjson-dev

Μπορούν να εγκατασταθούν με:

```bash
sudo apt update
sudo apt install make gcc libwebsockets-dev libcjson-dev
```

## Οδηγίες Μεταγλώττισης & Εκτέλεσης

Το Makefile είναι ρυθμισμένο ώστε η βασική εκτέλεση να διαρκεί 86400 δευτερόλεπτα,για μικρότερη διάρκεια μπορεί να τροποποιηθεί η αντίστοιχη χρονική τιμή.

Για μεταγλώττιση και εκτέλεση της εφαρμογής:

```bash
make run
```

Εναλλακτικά,για εκτέλεση χωρίς προκαθορισμένο χρονικό όριο:

```bash
make run4ev
```

Η εφαρμογή συνεχίζει να εκτελείται μέχρι να τερματιστεί χειροκίνητα με Ctrl+C
